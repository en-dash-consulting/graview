A record's page draws a blank fact an act the seat may run writes as an empty slot, Roadmap request:record-pages-draw-writable-but-blank-facts-as-empty-editable-slots. A placement made without its allocation or its role had nowhere on its own page to be given them: a blank fact was not drawn, and the act that writes it (`edit-placement`) surfaces only as the dashed editor on a fact, never as a button — so a new record's empty field could be set only from a form somewhere else. Now each field with no value that an act the seat may run writes — taking the value and asking nothing else — stands where the kind's page orders it (`display.page`, `set-page-fields`) as its label and a dim "add", a button named "Add Allocation" that the keyboard reaches; pressing it opens the same in-place editor a value opens, a choice opening on no choice, and saving fills the fact. A blank no act writes (a `fixed` field) stays unsaid, and a seat the policy keeps from the act — a reader — is offered no slot; a file field is still filled where its files are put (FR-163), and another app's address or a record in one is still picked where it is drawn. Underneath, `readableFields` takes `blanks` — the fields to say as empty slots, never on a glance — and a `ReadableField` read that way carries `blank: true`; `recordFacts` passes `blanks` through, the derived record page asks `blankWritable(store, id, principal)` for them where values are changed in place, `RecordField` draws the slot, and `EditableValue` takes `blank`. Pages' `a-blank-fact-an-act-writes-is-an-empty-slot.test.tsx` and core's `a-blank-a-page-may-fill-is-said-where-it-stands.test.ts` hold it, and a new harness, `verify-blank-facts`, opens a staffing firm's placement in three engines and finds the slot by Tab, fills it by Enter, and finds no slot for the fixed field or for a reader (aBlankFieldAnActWritesIsAnEmptySlot, aBlankFieldNoActWritesStaysHidden, aReaderSeesNoEmptySlot). And a filled value is drawn as a control only where an act the seat may run writes it, Roadmap request:in-place-editors-ignore-grants: the in-place editors offered every act that wrote a field whatever the seat's grants, so a reader saw dashed values the store would refuse; `editableFields` now takes `{ principal }` and offers only the acts `store.permittedMutations` gives it, `useEditableFields` passes the seat's, and a reader's values are read-only on every face (the same check the blank slots make; aReaderSeesNoEditableValue in `verify-blank-facts`).
