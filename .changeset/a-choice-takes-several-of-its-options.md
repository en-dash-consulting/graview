A choice takes several of its options at once (FR-233), Roadmap f-multi-select-enum; `capabilities().shipped` gains FR-233. An enum took one option and a list took free words, so a memo's recipients — the CTO, the developers, QA, product — had nowhere to be several fixed options. A field is now `{ "type": "enum", "multiple": true, "options": [...] }`: the one shape an enum already has, so its `options`, its `optionLabels` (0.1.56) and `set-options` carry over unchanged, rather than a `list` with `options`, which would have given options a second home on a type whose `of` already says what it holds. It compiles to a list of the options (`z.array(z.enum(...))`), which `fieldSpecOf` reads back as the same field and the generated types say as an array of the union. A record's facts, a card, a glance, a change's sentence and a sheet (`/csv`, `/words`) say each option it holds by its label, "CTO, QA"; a form on the routed face asks with a box per option and sends the list of those ticked, in the options' order; a record's page changes it in place as the same boxes; the scene's ask strip already toggled several of a choice. A list filters by one of its options (`/arrange`, the filter chips and a view's `where`) and is neither sorted nor grouped by it — a record would stand in several groups — which `graview check` says of a list declared grouped by one and of a board bound to one. An import (`/import`, `import_rows`) reads a cell that lists them, "CTO; QA" or "developers, product"; a Notion connection holds it in a multi-select (`notionFieldType`, `several choices` in `NOTION_FITS`), never a select; a derived act's JSON Schema and tool schema ask for an array of the enum (`/json-schema`); a migration keeps the options that fit when a field changes between one and several (`coerce`). The studio's meta-schema has `multiple` on a field, `add-field` and `retype-field` take it, `set-multiple` changes it alone, and a declaration's list of an enum round-trips through the studio's graph, its source and its edits. `multiple` on a field that is not an enum is refused as a shape finding at `kinds.<kind>.fields.<field>.multiple`, in `graview check` and in `document.schema.json` alike; a default outside the options, or a single one where a list is wanted, is `default-option`. The graview-node-kind skill says the shape in one line. `a-choice-takes-several-options.test.ts`, `a-form-asks-for-several-options-as-boxes.test.tsx`, `several-options-changed-in-place-as-boxes.test.tsx` and `a-choice-of-several-round-trips-through-the-studio.test.ts` hold it, and the field-types harness opens a rehearsal's sections on the page and in the form.

Reading the shape, compiling the list and saying its options costs a hosted page 0.5 KB more up front (522 bytes minified, 278 fewer gzipped), and a page handed a compiled app 0.2 KB (161 more minified, 271 fewer gzipped), under raises naming this changeset; the pages face alone 2_246 / 565 more, a visitor's form alone 709 / 126, a visitor's form handed a compiled app 863 / 102, every face 1_480 gzipped, the guest host 36 / 12 registering a view, 6 drawing a worker and 72 on the open kit, and Cloud's worker 4_641 bytes, each under a raise of its own; the scene face before it draws measured 1_054_746 B (1031 KB).

Compatibility: ops and primitives — unchanged. Stored formats — unchanged; a record of such a field holds a JSON array of its options, as a list field does. The wire — unchanged. The declaration and check finding codes — a field gains the key `multiple` (an enum's only; on any other type it is refused as `shape` at `kinds.<kind>.fields.<field>.multiple`, as `options` is), `default-option` also judges a list default, `retype-field` takes `multiple`, and a Notion `connection-field-type` finding names `several choices` for such a field; every other code is unchanged. Derived tool names and input schemas — a form field of a list of an enum is now one `choice` control with `multiple: true` where it was a `list` of `choice` controls (`FormField`); a tool's input schema for the argument is the array of the enum it already was. What Graview Cloud does: declares `"multiple": true` on an enum that takes several; draws a `choice` form field with `multiple` as checkboxes if it draws its own forms.
