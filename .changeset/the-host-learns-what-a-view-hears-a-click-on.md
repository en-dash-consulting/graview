An audit of a page learns from the host what a worker view hears a click on. A `<div>` a view only hears a click on (`graview.on("click", ".more", …)`) is something a person clicks that the keyboard must reach, and a headless run knew which elements those were; the live host did not, so an audit of a page had to be handed `clicked` by whoever ran it, and one that was not passed such a `<div>` as plain words. A worker view's runtime now tells its host every selector it hears a click on — once a microtask after one is added or let go, the whole list, at most 200 — as `{ type: "clicks", nonce, selectors }`; the host keeps them on the region it draws the view in, and `auditView` reads them there when it is not handed `clicked` (handed, what it is handed wins). Guest's tests find the runtime saying its selectors as they change, the session handing on only its own nonce's strings, and an audit of a region its host kept selectors on finding the click-only `<div>` and the "More" button that says no state; `pnpm verify a11y` audits each view on the page both ways and finds them agree ("aPageAuditLearnsFromTheHostWhatTheViewHearsAClickOn"). With the wider ring of `a-wider-ring-is-whole-at-the-regions-edge`, the guest host carries about 0.1 KB more before a worker is drawn and when registering one, 0.9 KB more (0.3 KB gzipped) drawing one on the open kit, and a worker view's runtime 0.3 KB more, under raises of those budgets by that (`scripts/budget-raises/the-host-learns-clicks-and-a-wider-ring-*.json`).

Compatibility: the wire gains one message from a worker view to its host, `{ type: "clicks", nonce, selectors }`; a host before this version drops it unread, and a view before it never sends it. `createGuestHost` takes `onClicks`. `auditView` with no `clicked` on a live page now judges what the view hears a click on, where it judged nothing heard; a page audit that was handed `clicked` says what it said. The declaration, the stored formats, check findings and derived tools are unchanged. What Graview Cloud does: its page audits need no longer pass `clicked` for a worker view once it takes this version.
