An id never quotes a field a sight keeps from a role. Field sight keeps fields, not ids, and an id is served wherever its record is: the seat's snapshot, the log (a change withheld as "A change you cannot see" included) and every link that names the record. A document's act that made a record minted its id from the field it names the record by, so where a sight's `hide` or `fields` kept a tip's title from the public, the public read the title in the id (`tip:secret-merger-plan`). Now a document's act mints a record's id from its kind's name (`tip:tip`, `tip:tip-2`) when some sight may keep the field it would be named from from some role (`mayKeepField`). An act of the app's own that hands `freshId` an argument for such a field gets the same, and an import mints so when the name it worked out quotes such a field. A kind no sight keeps a name field of is minted as before (`topic:budget`). `graview check`'s `sight-hides-a-labeled-field` says, of a label, that a new record's id is minted from the kind's name, and that an act of the app's own that hands `freshId` a name built from the kept field would quote it. Core's tests hold it (`an-id-never-quotes-a-field-a-sight-keeps.test.ts`). The store mints on every page, so a hosted page carries 0.3 KB more up front (307 bytes minified, 150 gzipped; 308 / 113 handed a compiled app), under raises naming this changeset. With the two changes beside it, the pages face carries 423 / 123 bytes more, a visitor's form handed a compiled app 411 / 165, every face 754 / 373 and Cloud's worker 1,752, each under a raise of its own, and the scene before it draws is held under 1023 KB.

Compatibility: ops and primitives, stored formats, the wire, and derived tool names and input schemas — unchanged. The declaration and check finding codes — no new code: `sight-hides-a-labeled-field` says more of a label. A record made where a sight keeps its kind's name field from a role gets an id from the kind's name where it got one from that field; ids already held are kept. What Graview Cloud does: nothing.
