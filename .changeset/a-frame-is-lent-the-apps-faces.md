A frame guest is lent the faces the app lends its views (Roadmap f-faces-lent-to-frames). Since 0.1.71 `brand.views.fonts` reached worker views alone, and a `guestView` frame fell back to a generic stack. The frame's host now reads each face where a worker view's is loaded from — a file the app holds where `asset` serves it, or an `https:` address on an origin `fonts.origins` lists — held to the same 2 MB, the last lent winning a shared name, and hands it over the port as a `data:` font (`GuestFont`, a new `fonts` message); the client puts it in the frame's document, so a guest's `font-family: "Rock Face", serif` draws in it and loads nothing. The frame's policy needs `font-src data:` and nothing wider. `mountGuestView` and `guestView` take `asset` (the page's host's by default, for `guestView`) and `fonts`; a face not lent is said to `onProblem`, and `guestView` says it in the console. Frames on one page dressed in one brand share one reading of its faces, fetched and encoded once. A file is read as a face only where it answers as a font (`font/*`) or as bytes that say nothing more (`application/octet-stream`) — for a worker view too — and one that answers as anything else is said, with what it answered. The frame says it has drawn once its faces are read, or after two seconds at most (`FACES_WAIT_MS`), saying which face did not arrive; it is handed the face when it does. The inlined client's text changed, so its hash (`GUEST_CLIENT_SHA256`) did too. `guestView`'s new options are drawn with the page, so a hosted page carries 0.2 KB more up front, and 0.2 KB more when handed a compiled app; the faces' reader is fetched only for a frame whose brand lends one.

Compatibility: ops and primitives — unchanged. Stored formats — unchanged. The wire — a host sends a frame a `fonts` message ({ type: "fonts", fonts: [{ family, weight?, style?, src }] }); a client before this one ignores it; a face file, for a frame or a worker view, is now read only when its host answers a font type (font/*, application/font-*, application/x-font-*), application/octet-stream or no type, so a host that answers a font file as text/html or the like has its face said and not loaded. The declaration and check finding codes — unchanged. Derived tool names and input schemas — unchanged.
