An empty choice of a record is no value, a view's place says its acts on every path, an argument naming nothing is warned of, and a document's Download asks for an attachment (HQ f-forms-and-downloads-follow-ups). An agent sending `"to": ""` for an act's optional record argument was refused ("names a record that is not there"), where a form leaving it empty applied; `""` for a record argument the act may go without is now taken as no value at the one boundary every call crosses (`Store`, `compileMutation`), and the link it would make is skipped, for an argument said with no type and one said as a string alike; a record the act must be handed is still refused. `viewPlaceOf` (`@graview/core/seat`) gave a titled view's place no `acts` and no `reads`, where the place a page registers for the same view (`registerWorkerView`) had both, so the seat and a headless check did not know a form for a kind as the bar does; it now says them the same. A declared argument with no type that no effect reads was asked as a choice of any record of any kind, and nothing said so; `graview check` now warns `act-arg-unread` at `acts.<act>.args.<arg>` ("\"add-dish\" declares \"helper\" with no type, and no effect links it, so it is asked as a choice of any record of any kind"), saying to link it in an effect or give it a type where it is a value. A PDF's own Download, and another document's name that downloads it, now link to the file with `?download=1`, as a video's and a full-size picture's Download do. Core's tests hold `""` applied with no link and refused where the record is required, the place's acts and reads the registry's, and the warning given and not given; primitives' hold both document links asking for an attachment and Open opening the file as it is.

Compatibility: the declaration and check finding codes — additive: a new warning, `act-arg-unread`, on an act's argument declared with no type that no effect reads; nothing that passed is refused. Ops and primitives — changed: a call's optional record argument sent as `""` is applied without it, where it was refused, and the op log records the call without an argument declared with no type (one said as a string keeps its "" and makes no link). The JavaScript API is additive (`acts` and `reads` on `HostView`, and on the `Place` `viewPlaceOf` returns). The wire, stored formats, and derived tool names and input schemas — unchanged. A host serving files answers a document's Download with `?download=1`, as it answers a video's.
