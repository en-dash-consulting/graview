Every problem a view's host reports now says a code beside its sentence. Graview Cloud counts what goes wrong in its views (a part that failed, a frame held by the growth guard) by matching the framework's English, so rewording a sentence silently stopped the count. `onProblem` on `mountWorkerView`, a registered worker view's definition, `mountGuestView` and `guestView` is now called `(said, { code, part })`, and `createGuestHost`'s `onHeld` `(said, height, { code })`. The code is one of a closed list, `VIEW_PROBLEM_CODES` (`part-failed`, `held-by-growth-guard`, `face-not-lent`, `face-not-loaded`, `face-late`, `own-face-refused`, `picture-left-out`, `link-goes-nowhere`, `image-refused` and the rest, twenty-three in all), with its types `ViewProblemCode` and `ViewProblem`, exported from `@graview/guest/host/frame`, `/host/worker` and `/host/views` (the types also from `/host`); `part` names the part for `part-failed`. A sentence may still be reworded in any version; a code is never renamed or reused. The list is pinned whole by a unit test (`a-views-problem-says-a-code-beside-its-sentence`), which also holds that the package's README documents each code, and the tests of the parts that failed, the frames held, the faces not lent or late, the links and images refused, the pictures left out, the jumps and file links and the full-screen viewer say the code each gives. A frame guest's navigate that goes nowhere, told only to `onLost` before (and to the console by `guestView`), now reaches `onProblem` too, as `link-goes-nowhere`. A hosted page stays within its budget; a page that hosts guest views loads 562 / 269 bytes more before a worker is drawn and 544 / 288 more registering one, the chunks that draw a view up to 908 / 303 more, and every face 1_688 / 709, under raises named `a-views-problem-says-a-code-*` in `scripts/budget-raises/`.

Compatibility: ops and primitives, stored formats, the wire, the declaration and check finding codes, and derived tool names and input schemas — unchanged. The JavaScript API is additive: a host's one-argument `onProblem` is called as before. What Graview Cloud does: count `ViewPartFailed` by `code === "part-failed"` and `ViewHeld` by `code === "held-by-growth-guard"`, rather than by the sentence.
