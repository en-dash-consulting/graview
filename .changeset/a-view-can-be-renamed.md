A view can be renamed (Roadmap f-rename-view). A remixed app's views keep the names they were written under — its home is still `eagles-nest` — and replacing a view goes by name, so there was no way to give one its own. The edit `rename-view` (`{ "op": "rename-view", "view": "eagles-nest", "to": "vendor-board" }`, either name bare or as `view:<name>`) moves every `view:<name>` the document holds — `pages.order`, `pages.first` and `pages.primary`, the only places a document names a host's view — and says so: `The view "Eagle's nest" is now called "vendor-board"; the order, the place the app opens on and the bar name it so.`, or `The home's view "eagles-nest" is now called "welcome".` for a view nothing in the document names. It is refused, at `edits.<n>`, for a name that is not a view's name (`"Vendor Board" is not a view's name: lower-case letters, digits and hyphens, like "vendor-board"`, the manifest's own rule), a name another view has (`another view is already called "shortlist" (Shortlist)`), a view the host does not keep where `EditOptions.views` says its views, and, where it does not, a view nothing in the document names. A later edit in the same batch names the view by its new name. The view itself and its kept versions are the host's, as they were; the edit is what tells the host to move them. Core's test renames a view the order, the bar and the place the app opens on name, and the document checks as clean as before against the host's renamed views; a taken name and a name that is none are refused.

Compatibility: ops and primitives, stored formats, the wire, derived tool names and input schemas — unchanged. The declaration and check finding codes: additive, one edit op in `EDIT_OPS`; a build that predates it refuses `rename-view` as an edit it does not know. What Graview Cloud does: offers `rename-view` in propose_change, passes the views it keeps as `EditOptions.views`, and on applying it renames the stored view under the new name with every kept version, its hidden or recently deleted entry and its manifest's `name`, in the same change as the document.
