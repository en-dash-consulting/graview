Better UI's checks read what the page draws, so a correct draft passes the first time. Graview Cloud reproduced three faults with no model at all. First, a view's records were named by a card's words run together: a status tag beside the record's link read as "bookedThe Velvet Notes", and an unchanged draft failed as having lost it. Each record is now named by the label its kind gives it, where the card says it, or else by its `data-record` link's own words (`recordLabelsOf`). Second, a part of a view was found by its heading's words, so a draft that only reworded the heading it was asked to reword failed as "no longer drawn". A part is now found by where it stands. Where the person asks for a heading's words to change, that part's headings may change in place (`renamedInPlace`, `lostUnlessReworded`, and `drawnFindings`' new `mayReword`), and the agent is no longer told to keep them (`you_may_reword` in its prompt). Every other heading is still held. Third, a built-in list page handed the agent no records, because it read a `label` field that a vendor does not have. It now names each record with `labelOf`, so a draft that drops every status fails.

What a check found is said by its kind (`findingKind`: `record-lost`, `fact-lost`, `section-lost`, `did-not-draw` and the rest). A part no longer drawn is never shown on the panel as "it didn't draw", and a finding with no kind of its own is said in its own words instead of "something didn't draw right". If judging a draft throws, the agent is handed what went wrong. A host can log every draft's findings whole: `HostAi.onDraftChecked` is told the part, which draft of the turn it was, whether it passed, and each finding with its kind. The panel's check steps carry the same findings. When two drafts in a row fail the same way, the turn ends (`ended: "stuck"`) with a plain sentence such as "I tried twice, and the new design still loses details on 2 vendors. Keep it anyway, or stop?". The panel then offers Keep anyway and Stop. Keep anyway is offered only for a draft that drew. A kept bubble whose host note already says it was kept now reads "Kept until this page reloads." once. Tests: `better-ui-judges-a-draft-by-what-the-page-draws` and `the-better-panel-says-kept-once-and-offers-a-choice-when-stuck` (primitives), `better-ui-reads-the-records-a-list-page-draws` (pages), `a-draft-that-fails-the-same-way-twice-is-said-plainly` (tools), and new `section` harness claims: `aDraftThatChangesNothingPasses`, `aHeadingRewordedAsAskedPasses` and `aDraftThatFailsTheSameWayTwiceOffersKeepAnywayOrStop`. Every face grows by 6.4 KB (2 KB gzipped), under a raise of its budget (`scripts/budget-raises/better-ui-checks-read-what-is-drawn-every-face.json`). A hosted page's first load is unchanged.

Compatibility: ops and primitives — unchanged. Stored formats — unchanged. The wire — unchanged. The declaration and check finding codes — unchanged. Derived tool names and input schemas — unchanged. `HostAi.onDraftChecked` is optional and additive. `DesignAgentResult.ended` gains `"stuck"`, and `DesignAgentEvent.kind` gains `"stuck"`.

What Graview Cloud does: pass `onDraftChecked` on the `HostAi` it lends a page to log why a Better UI draft failed, by kind and in full. `scripts/better-ui-checks.mjs` should hold all three of its checks.
