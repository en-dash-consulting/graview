Typing together converges whatever the network does: the sixth phase of collaborative text, hardening. A seeded fuzz of the live protocol — three pages typing into one text through `openRemote` and a real handler, with lines held, frames sent twice, connections broken with frames lost or delivered first, and each page taking back its own runs at random, a few thousand steps — found five ways an undo of typing went wrong, all fixed. An undo of a run still held behind another reached the server before that run, and was refused: a held run's answer is now waited for before an undo of it is sent. An undo of a run that came to nothing — let go of on the page, or answered with no op because what it typed was deleted meanwhile — was sent and refused: it is let go of quietly. A pending undo of a pending run was lost when what landed under them carried the run, which was applied again under new op ids, so Ctrl or ⌘ Z took the same run back twice: `Store.rebase` and `adopt` read an undo's target by the batch of the ops they rolled back. A run claimed a revision past an undo of its own not yet answered, and was refused for offsets the text then did not have: a run waits for the answers to this page's pending changes to the same field ahead of it. And an undo carried to nothing blocked every earlier undo of typing into that field: it stands in nobody's way. `pnpm verify typed-together` asks six more things, in three engines: a page slowed four times types beside a quick one and both converge with the store; a page cut off mid-run keeps typing, comes back, and its run lands carried over what the other typed meanwhile; each person's ⌘Z takes back only their own run; a word composed with an input method lands whole (Chromium, where it can be driven); a seat whose sight hides the field is served no splice, no caret and none of the words; and a reader of op format 2 is sent whole values that fold to the store's text. A hosted page carries 0.3 KB more up front (the rebase reading an undo's target by batch, and the remote's set of runs let go of), under raises of the hosted page's budgets (`scripts/budget-raises/typing-together-converges-whatever-the-network-does-*.json`).

Compatibility: ops and primitives — unchanged. Snapshot and log formats — unchanged. The wire — unchanged: a page sends fewer undos a server would refuse, and none in a different shape. The declaration and check finding codes, derived tool names and input schemas — unchanged. The JavaScript API — unchanged on the public entries; `TypingWire` and `TypingInsides`, which `remote.typing` makes for itself, gain `ahead` and `letGo`. What Graview Cloud does: takes this build; nothing to change.
