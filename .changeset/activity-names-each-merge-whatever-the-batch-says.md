Activity names each merge, removal and archive in a batch, whatever the batch calls itself (Roadmap f-activity-names-merges). A batch that carried its own intent — an agent's "Cursor: merge-actor, edit-threat" — was one row in those words alone, so a count that dropped (software 79 → 78) was never explained. The row now says the batch's intent and then, by each op's own sentence, every op that takes a record out of the counts: "Cursor: merge-actor, edit-threat — Merge APT-1 into APT1; Remove Comment Crew; Archive Sandworm". An op that changes a record and takes nothing out is still said by the batch's words; an undo says what it took back in its own; an op the seat may not see is not said. Both faces' Activity read it, and so does each change inside a digest.

Compatibility: ops and primitives, stored formats, the wire, the declaration and check finding codes, derived tool names and input schemas — unchanged.
