An import links a cell to any row of the same sheet, in one call (FR-200). Graview Cloud, building AI Atlas: `importRows` read a link cell against the records there before the call and the rows above it, so a self-relation (`model.succeeds → model`) or two rows naming each other was refused, and people imported twice. Now every row of the call is read and named before any link cell is, and a cell names a record of the app or any row of the call, above it or below it: by what the call matches by (`match: { column, field }`) and then by label, and failing both, a record of the kind by what the call matches by. The links whose far row comes later follow the records in the same batch, one op per row ("Link Claude 3 to Claude 2"), so one undo takes the rows and their links together, and `admit` is asked the whole call. A row that names a row which is itself refused is refused too, and says which ("row 3, which Succeeds names as “Claude 2”, is refused"), read again until none is; two rows of the sheet called the same are said rather than guessed between ("could be any of the 2 rows of this sheet so called"); and a name nothing answers to now names its column ("no model is called “Claude 9” under Succeeds"). The preview is the same reading, so it says what lands. `core`'s test imports a sheet of models whose rows succeed later rows and two that rival each other in one call, compares the preview with what lands, undoes it whole, names a later row by its key, and refuses a name nobody has, a row naming a refused row and a name two rows share. `docs/import.md` says so. `capabilities().shipped` gains FR-200.

Compatibility: ops, stored formats, the wire, the declaration and derived tools are unchanged; `capabilities().shipped` gains FR-200. A sheet that imported before imports the same, except that a link cell may now name a row below it, and the refusal for a name nothing answers to ends with "under <column>". What Graview Cloud does: deletes its two passes under one batch (`packages/room/src/import.ts`, INTERIM(FR-200)) once `capabilities().shipped` has FR-200, and calls `importRows` once.
