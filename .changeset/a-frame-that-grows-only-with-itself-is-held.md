A frame guest that grows only with its own frame is held, and the host is told why (Roadmap f-guest-growth-guard). A frame takes the height its guest asks for, up to `limits.maxHeight`, and Graview Cloud lets a frame of many views be 20,000px; a page sized by `100vh` asks for its frame's height and its margin each time the frame is made taller, so it grew with itself to the cap. The guest session now sets each height asked for against the one last given: where it is more by the same pixels or the same share a few times running, with nothing pushed between, that height is refused for a moment. Rows or pictures of one height look the same, so a guest that asks another height meanwhile is one whose content grows, and it is taken and the guard starts over; one that asks nothing new is given the refused height after all, and watched as long again. A page sized by its frame asks once more by the same step as soon as its frame has moved, and only then is it held at the height it was given — content that had finished asks nothing, keeps its whole height and nothing is said — and the host is told why: "The view "tall" asked to be 32px taller than its frame each time its frame was made taller, 5 times running, so it is held at 320px: a page sized by its own frame (100vh) grows with it. Size the page by its content, or ask for a height (guest.size)." — to `onProblem` (`mountGuestView`, `guestView`, which says it in the console too) and to `onHeld` (`createGuestHost`), and the frame wears `data-guest-view-held`. A lower height is always taken. `guestView` takes `onSize`, told each height once the frame has taken it, and `onProblem`. It is drawn with the page, so a hosted page carries 0.1 KB more up front, and 0.1 KB more when handed a compiled app.

Compatibility: ops and primitives — unchanged. Stored formats — unchanged. The wire — unchanged: a `size` message is read as before, and a height the guard holds is not passed on. The declaration and check finding codes — unchanged. Derived tool names and input schemas — unchanged.
