A drop says when each file was taken, and is never offered where it would be refused (the thirteenth walk, a camera-trap survey). A detection's act cannot go without the instant it was taken, and photographs dropped on a station's contact sheet were offered a drop target and then refused, every one: the host filled the file and the record's name and left the time out, though each file says when it was made. Now a required time the act that makes the record takes — an instant or a day — is the file's own (its `at`, from the file's last-modified time), else the moment of the drop. An act a drop would still leave asking for something no file says (a collar number, a count) makes no drop target, and the sentence names what it asks for: "\"Log a tagged detection\" asks for \"collar\", which no dropped file says, so nothing dropped here can become a detection."
Compatibility: additive for a host and for views. Ops, stored formats, the wire, the declaration, check finding codes and derived tools are unchanged; a drop target an act would refuse is no longer offered, and a required time is filled from the dropped file.
