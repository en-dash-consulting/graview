A project `graview create` writes takes a picture on a record in development (the thirteenth walk, a camera-trap survey). The graview-node-kind skill's first example declares `imageField()`, and a project that followed it drew the field's editor as "This host doesn't take files, so none can be added here.": the scaffold handed neither face any `files`, and its dev server kept none. Now its `vite.config.ts` adds `devFiles()` beside `studioDoor()`, and `main.tsx` hands the scene and the pages `filesAt("/__graview/files", …)` while the dev server runs (pictures, videos, PDFs and plain text, up to 10 MB each, kept in memory); a built page still hands none, and the comment says to hand the host's own when it is deployed.

Compatibility: ops, stored formats, the wire, the declaration and derived tools are unchanged; only what `graview create` writes for a new project changes.
