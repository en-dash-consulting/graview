A host can hand the page a compiled app (FR-123). Graview Cloud compiles an app's document on its server at every change, and its shell then compiled the same document again in the browser. That put the document reader, its validator, the expression and template parsers and the view checker in every hosted page's first chunk, only to arrive at an app the server already had. Compiling is now two halves. The first reads and judges a document and says what it compiles to as plain data. The second builds the app from that data. `serializeCompiled(compileDocument(document))` gives the first half's answer as JSON, with every template and expression already parsed, and `appFrom(compiled)` builds the same app from it in the page. `compileDocumentWithoutCheck` builds its app the same way, so the two cannot drift. A round-trip test holds them together over every fixture document, every Cloud template and the example apps' declarations as documents. It checks the same document hash, places, `describePlace` output on a seeded graph, act schemas, act results and ops, broken rules, labels and checker findings. `appFromOrCompile({ compiled, document })` from the new `@graview/core/compiled` entry builds the handed app, or compiles the document when none was handed or the one handed is of a format this build cannot read. It fetches the compiler only then. The compiled app says `graview-compiled@1`; another format is refused as `compiled-format`, and parts that do not match their document as `compiled-shape`. docs/stability.md says how the format is versioned. What stays in the page is what an app needs to run there: the field schemas the store validates with, the evaluator that judges act guards, rules, computed values and template parts, and the template renderer that says labels, refusals and rule sentences. The framework's hosted page handed a compiled app loads 512.9 KB up front, where compiling in the page it loads 557.1 KB (556.1 before this change). Graview Cloud's shell, built in memory against these sources, goes from 554.8 KB to 511.4 KB, and @graview/core's share of it from 186 KB to 143. `pnpm verify hosted` holds two more claims: that page is at most 520 KB up front, and it carries no compiler. Reading a template moved to a module of its own so the renderer no longer reaches the parser. The ship skill says how a host serves document apps this way.

Compatibility: additive. `@graview/core` gains the `./compiled` export (`appFrom`, `appFromOrCompile`, `serializeCompiled`, `COMPILED_FORMAT`, `sayFindings` and the `CompiledApp` types), and `@graview/core/document` gains `serializeCompiled`, `appFrom`, `COMPILED_FORMAT` and the same types; the compiled-app format is new and versioned (`graview-compiled@1`). `compileDocumentWithoutCheck` and `compileDocument` return what they returned. Ops, stored formats, the document format, wire messages, check codes and tool schemas are unchanged. `capabilities().shipped` gains FR-123.
