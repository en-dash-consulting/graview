A worker view's every stylesheet is drawn, in the order it gave them. Roadmap `feature:views-a-second-graview-style-call-silently-drops-the-first-stylesheet`, filed from Threat Watch by Graview Cloud: a view that called `graview.style` twice — the app's shared design-system sheet, then its own — drew with only the second, and nothing said the first was gone. Each call now adds its sheet after the ones before; the runtime sends the host the whole list (`{ type: "style", sheets }`), and the host draws every sheet, judged each on its own as one sheet always was, so a sheet left open swallows nothing after it, and all of them held to the one 64 000-character budget between them, a sheet past it refused for its size with the ones before it drawn. A sheet given again is the sheet already there, so a view that styles on every push adds nothing and sends nothing. A headless run draws the same sheets the page does: its transcript holds `sheets`, and `drawTranscript` judges them as the page does.

`guest`'s tests send two sheets through the view's runtime and find both in the message, a sheet given again sent once, the page drawing the first sheet's rules ahead of the second's, a sheet left open not swallowing the next, a sheet past the shared budget refused for its size, and a headless run's sheets drawn to exactly what the page draws. `guest-sandbox --transport=open` draws its showcase from two sheets in Chromium, WebKit and Firefox and finds both drawn, the second after the first. The `graview-view-drawing` and `graview-worker-view` skills and the guest README say it. The guest host registering a worker view carries 43 bytes more (5 gzipped) and drawing one on the open kit 284 (80 gzipped), each under a raise that says so (`scripts/budget-raises/a-views-every-stylesheet-is-drawn-*.json`).

Compatibility: the wire changes — the `style` message a view's runtime sends is `{ type: "style", nonce, sheets: string[] }` where it was `{ css: string }`, and a host from before this drops a runtime's `style` from after it unread (the runtime and the host ship together in `@graview/guest`, so a page that loads both from one version is whole). In the API, `HeadlessTranscript.css` is `sheets`, `drawTranscript`'s second argument is the list of sheets, and a guest host's `onStyle` takes the list. A view's source is unchanged: one call draws as it did.
