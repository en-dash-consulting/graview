A document's typeface is a list of names quoted in pairs, and an embed's scoped theme keeps every rule in its box even when it is not. A face with a quote it never closed — `"display": "Georgia'"` — passed `graview check` (the check took the quote off before it looked the name up) and the page's brand (which refused only `url(`, `@import` and `;{}<>\`), and was written into the embed's style sheet. CSS ends a string at the end of its line, but `withinTheBox`, which puts every rule of an embed's sheet under its element, read the string on to the next matching quote, so it missed where the block ended and left the rules after it as they were: 43 selectors (`h1`–`h4`, `code`, `kbd`, `samp`, the button states and many `.graview-*` rules) restyled the host page outside the embed, through the whole embed, the pages embed and a visitor's form alike. Now one rule judges a face in the checker and in `brandOf`: each family is a name with no quote in it, or one in a single matching pair with none inside, and a face with a line break, a control character or `/*` is refused, so `"Times New Roman"` and `'Source Serif 4'` are taken and written as given while `Georgia'` is refused (`brand-font`: "Georgia' is not quoted in one pair") and never written. And `withinTheBox` ends a string at a line break as CSS does, so a face that reached it some other way still cannot carry the rules after it out of the box. `the-whole-brand-is-in-the-document.test.ts` holds seven unbalanced faces refused and unwritten and four quoted ones taken; `a-scoped-theme-styles-nothing-outside-its-box.test.ts` reads the sheet as CSS does and finds every rule in the box for brands with an open quote in a face. The one rule rides with the brand a page compiles, so a hosted page carries 0.4 KB more up front (433 bytes minified, 223 gzipped), and one handed a compiled app 0.4 KB (433, 161), under raises naming this changeset.

Compatibility: ops and primitives, stored formats, the wire, derived tool names and input schemas — unchanged. The declaration and check finding codes — no new code: `brand-font` is also said of a face with a quote not closed in its pair, a line break, a control character or `/*`, which compiled before and is refused now; a page compiled without the check leaves such a face out, as it leaves out one that loads.
