Typing is said in words: the fifth phase of collaborative text. A person writing a paragraph sends a run of typing every word, and each was a row of its own; now a run is said as what it wrote, where and how much — "Ada wrote in Kitchen's notes (+42 −3)" — and one person's consecutive runs into one field are one thing. A keystroke's own sentence (`type-text`'s intent) says "Wrote in Kitchen's notes (+5 −1)". The timeline folds them into one tick (`ticksOf`: `batches`, every gesture's batch, and `typed`, the field and the counts; "Restore to here" stops before or after a run, not inside it), Activity into one row with one undo that takes the run back whole (`foldDigests`' row says `typed`, and `typedRowWords` on `@graview/core/tidying` says it), and `historyInWords(store, { me?, limit?, context? })` on `@graview/core/history` is a history newest first in sentences — what an agent's history answer says — each run of typing with the spans it put in and took out (`typedSpans`), never the field's text. `typedRun`, `typingWords`, `typingSentence` and `typedCounts` are there too. A notification says a field typed into as what was put in and taken out (`MatchedRecord.fields[].typed`: `{ inserted, removed, spans }`, with no `before` or `after`) rather than the whole text twice, and is told once, when the typist stops: `holdTypingRuns(hook, { quietMs })` on `@graview/core/subscriptions` holds a match that is a run of typing and joins the same person's next run into the same field for the same subscription into it — one match, every batch (`SubscriptionMatch.batches`), the counts added — until `TYPING_QUIET_MS` (5 s) pass with no more, or another match for that subscription comes, which is told after it. `watchSubscriptions` (`typingQuietMs`) and `@graview/ship`'s handler (`typingQuietMs` beside `onSubscriptionMatch`) hold through it, and tell what they hold when they stop or close. The app as it stood partway through a run folds the text typed so far (`pastOf`), and an agent reads a field typed into whole, as before. `PagesApp` takes `typing` (and `context.typing`), handed to the provider it puts under the routes, so a host that draws the pages alone, with no embed around them, edits a field typed together live; a short string stays a whole value with a Save, which the graview-pages skill says why. The scene face fetches 1.5 KB more before it draws (Activity's fold and its words), and its limit before it draws moves to 995 KB; the pages face alone carries 0.2 KB more, under a raise (`scripts/budget-raises/typing-is-said-in-words-pages-face.json`). Core's tests hold that a run is said with its counts, that one person's runs are one tick and another's breaks it, that the history in words says spans and never the text, that Activity folds a run, that the past partway through a run holds the text so far, that a notification says spans, and that a run is told once its typist stops and before what comes after it; tools', that an agent reads the field whole and its history in sentences; pages', that the pages alone edit live when handed `typing`.

Compatibility: ops and primitives — unchanged; a `type-text` op's intent reads "Wrote in …" where it read "Type in …", and an intent is display only. Snapshot and log formats — unchanged. The wire — unchanged. The declaration and check finding codes, derived tool names and input schemas — unchanged. The JavaScript API — additive: `PlaybackTick.batches` and `.typed`; `historyInWords`, `ChangeSaid`, `typedRun`, `typedSpans`, `typingWords`, `typingSentence`, `typedCounts` and `TypedRun` on `@graview/core/history`; the `typed` row of `foldDigests`, `TypedRow` and `typedRowWords` on `@graview/core/tidying`; `holdTypingRuns`, `HeldTyping`, `TYPING_QUIET_MS` and `WatchSubscriptionsOptions.typingQuietMs` on `@graview/core/subscriptions`; `SubscriptionMatch.batches` and `MatchedRecord.fields[].typed`, where a spliced field used to carry its whole text as `before` and `after` (since collaborative text's phase 2, never released); `typingQuietMs` on the store handler's options; `PagesAppProps.typing` and `PageContext.typing`; `UndoTurn` takes several batches. What Graview Cloud does: takes this build; its `history` tool answers with `historyInWords` (or says a tick's `typed` with `typingWords`), and its notifications are told a run of typing once — a host that matches commits itself puts `holdTypingRuns` between `matchSubscriptions` and its delivery, and reads `fields[].typed` for a field typed into.
