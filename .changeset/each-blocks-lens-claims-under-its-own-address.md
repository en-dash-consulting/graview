Each blocks lens's blocks are claimed under its own address. Every lens drawn from blocks answered to one shared view name, `place`, for `BlockSlots` claims, so two lenses whose blocks said one key could not be claimed differently: a face's claim on one was a claim on both. A blocks lens's view is now its address, as `describe_place` names it — the lens titled "The offers" is claimed as `{ "the-offers": { top: Banner } }` — and two lenses that say one key each draw their own. `SpecPlace` takes the `view` its blocks are claimed under; unsaid, it is the slot, so the home is still `home`.

Compatibility: ops, stored formats, wire messages, the declaration, the compiled format and tool names and schemas are unchanged. A claim keyed `place` no longer reaches any lens; key it by the lens's address. What Graview Cloud changes: nothing.
