The browser's store takes the host's policy. `openRemote` judges a call in the browser before the server is asked, so the interface moves at once — under the app's own policy. A host whose store judges by more than the declaration says had the two disagree: Graview Cloud's room adds a sight (an app's owners see everything), so the owner of a sighted app was refused in the browser, "names a record you may not see", for a change the room would have made. `openRemote({ localApp })` now shapes the app the local store is built from — the first one, and every one `resolveApp` gives on a new declaration — so local judgement matches the host's. The server judges every call regardless.

Compatibility: the `openRemote` surface — additive: `RemoteOptions` gains optional `localApp`. Without it the local store is built from `app` as before. The wire, presence, ops, stored formats and check codes are unchanged.
