A hosted page has room again before the app draws: 20.7 KB less up front (6.4 KB gzipped). The wave before 0.1.29 left Graview Cloud's shell 94 bytes gzipped under its budget, and 20.6 KB of what it loaded first was zod's JSON-Schema writer, which only the seat calls, to write an act's tool, and the seat is fetched when first asked. It rode up front because a bundler places a whole file in the first chunk when the page can reach it, and every zod barrel a page imports to build an app's fields reaches the writer. A tool's JSON Schema is now written by graview from the schema's own definition (`core/src/schema/to-json-schema.ts`, fetched with the seat), so nothing on a page calls zod's writer and no chunk carries it. Built as Cloud builds it over the vendors document, the page that compiles its document goes from 564 089 bytes (191.4 KB gzipped) to 542 940 (185.0 KB gzipped), and the page handed a compiled app from 522 312 (177.0 KB gzipped) to 501 163 (170.6 KB gzipped): 21 149 bytes fewer each. Their budgets fall to keep about 8 KB of that as room: 538.0 KB (188.0 gzipped) from 554.0 (191.5), and 497.5 KB (173.5 gzipped) from 513.5 (177.5). Every face fetched together, and the embed with the studio handed in, are 10.6 KB more, since the studio's classic schemas keep zod's writer beside graview's; each is raised by a file of its own in `scripts/budget-raises/`. The pages face alone is 21.5 KB less. A test holds what graview writes equal to zod's, key for key, over every example app's acts and kinds, every document fixture, and every kind of schema zod has.

Compatibility: every name stays where it was, and `@graview/core/json-schema`'s `toJsonSchema`, `nodeJsonSchema`, `mutationToolSchema` and `schemaJson` write the same JSON as before, so derived tool names, input schemas and a tool surface's hash are unchanged; the one difference is that the object returned no longer carries zod's hidden, non-enumerable `~standard` property. Ops, stored formats, the document format, the compiled format and check finding codes are unchanged. What a host does: nothing; Graview Cloud's shell built from these sources loads about 20 KB less before the app draws.
