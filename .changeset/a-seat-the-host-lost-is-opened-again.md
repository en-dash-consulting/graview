A seat the host lost is opened again, and a seat's key is nobody's tab. The README sketched a hibernating host's seat keys as `seatOf: (key) => seats.get(key)` over a map in memory, and Graview Cloud's spike kept them so: the first wake emptied the map, every socket was told `error`, "no longer known", and served nothing again — and `openRemote` ignored the error, so the tab sat open and deaf. And a key built from the principal with its session in it made `publish` build one view per tab rather than per seat. Now a socket whose seat key the host no longer resolves — on a message, a `publish` or a `tell` — is told so in a sentence that says the host lost it and that it should open again, `{ t: "error", reopen: true, sentence: "The host no longer knows who this socket is: open it again, and it reads who you are from the new one." }`, closed with code 4000 when the peer can be closed (`LivePeer.close`, which `createStoreHandler` gives every socket), and served nothing more; `openRemote` hearing it opens a new socket, the host reads the seat from that upgrade again, and what the tab had not had answered is sent again and lands once. `seatOfTab(principal)` is the seat without its session (and without the session of the person an agent acts for): `createStoreHandler` hands `seatKey` that, never the tab, and a sight in `publish` and `tell` is kept under it, so two tabs of one seat are one view however the host opened them. The README's sketch keeps seat keys in the Durable Object's storage and makes them from `seatOfTab`, and says why.

Compatibility: the live wire — additive. The `error` message gains optional `reopen: true`; a client before this release ignores it, as it ignored the error, and reconnects when the host closes the socket. `LivePeer` gains optional `close(code, reason)`. A seat key the host no longer resolves is now told `reopen` with a new sentence where it was told "This socket's seat is no longer known to this app". `seatKey` is handed the seat without `session`; a host whose keys depended on the session gets one key per seat. `seatOfTab` is a new export of `@graview/ship` and `@graview/ship/runtime`. `WIRE_PROTOCOL`, ops, stored formats and check codes are unchanged.
