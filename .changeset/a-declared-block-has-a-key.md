A declared block has a stable key, and a face claims a block by it. n-dx's face drew a change's rewrites and the tasks it works on in its own hand and let the declared blocks draw the rest, choosing which by a title's words (`title === "Rewrites"`), so a title said differently dropped a section without a word. Any block in a view — a kind's card, row or page, the home, a blocks lens — may now say `"key": "rewrites"`; one that says none has a key derived from its sort and its place among the blocks of that sort beside it (`list.2`, the second list; `group.1.text.1` inside the first group), never from what it says, and counted whether a sibling names its own or not, so naming one never moves another's. `compileBlocks` keeps each key and `resolveBlocks` carries it on every resolved block, nested ones too. A face claims blocks by key, view by view, with `BlockSlots` from `@graview/primitives`: `<BlockSlots.Provider value={{ "change.page": { rewrites: Timeline } }}>` draws `Timeline` for that block, handed the block worked out, its record and the framework's own drawing of it to wrap or leave out, and the framework draws every other block as declared. A view is named as `describe_place` names it — `home`, `<kind>.page`, `<kind>.card`, `<kind>.row` — so a record a list draws inside a page answers to its own view's claims. A claim may be `lazy`: the framework's drawing stands in until it arrives. `graview check` refuses two blocks of one view under one key, nested or not, saying where the first is, and a key that is not a word or a few joined by hyphens (`view-key`); a seat drafting a view may give its blocks keys too.

Compatibility: ops, stored formats, wire messages, the compiled format and tool names and schemas are unchanged. The document format takes `key` on any block, where it was refused as an unknown key, and a declaration's `ViewBlock` types it. New: the check finding code `view-key`, an error; `key` on `SpecBlock` and `ResolvedBlock`; `viewKeys` beside `viewBraces`; `BlockSlots`, `ClaimedSlots`, `BlockSlotProps` and `BlockSlotComponent` on `@graview/primitives`, and `SpecBlocks` takes the `view` it draws. A document that compiled still compiles. What Graview Cloud changes: nothing.
