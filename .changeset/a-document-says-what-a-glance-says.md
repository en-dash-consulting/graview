A document says what a glance says. `compileDocument` passed on the checker's `glance-unchosen` note for a kind with more than five fields, and the note told the author to write `display: { glance: [...] }`, which a document had no word for: `"glance"` on a kind was refused as an unknown key. A kind in a document now says `"glance": ["price", "mileage", "body"]`, and it compiles to the definition's `display.glance`, beside the field labels. Each name is checked against the kind's fields (`glance-field`, at `kinds.<kind>.glance`). `editDocument` renames a field in the glance when it renames the field, and drops it when it removes the field; a glance left with nothing is removed and said. `diffDocuments` says "What a glance at a car says changes." for a different choice, and says nothing extra for a rename or a removal it already said. `toDocument` writes a TypeScript declaration's `display.glance` as the kind's `glance`, keeping only the fields the document could carry. For a document that has not chosen, the note is now at `kinds.<kind>.glance` and its fix says `"glance": [...]` on that kind, not the TypeScript `display` (FR-39).

Compatibility: the declaration — additive within `graview-document@1`: `kinds.<kind>.glance` is a new optional key, and every document that compiled before compiles the same, to the same app. The new `glance-field` error only reaches a document that says `glance`, which was refused before. The `check:glance-unchosen` note keeps its code and meaning; for a compiled document its path and fix are now in the document's words. `capabilities().documentFormats` is unchanged, and `capabilities().shipped` now names FR-39. Conformance fixtures: unchanged, since none says `glance`. Derived tool names and input schemas: unchanged.
