Every act refuses an argument it does not take (FR-121). Since 0.1.14 a derived `edit-<kind>` refused an argument it did not take, naming the ones it did; every other act parsed it away and ran as if it had never been given, so `set-quote { id, quote, colour }` set the quote and said nothing of the colour, and Graview Cloud kept a stray-argument check of its own in front of every call. Now a document's act, a TypeScript mutation and `remove-<kind>` are held to their shape too: `set-quote { id, quote, colour }` is refused as `InvalidArguments` (reason `invalid`) with "does not take "colour"; it takes "id", "quote"", and nothing in its batch lands. The framework applies it where every call crosses — `compileMutation`, before the input parses, so `apply`, `applyAll`, `preview` and every tool, socket and route reach it — and a product changes no code: a plain `z.object` input, which zod strips silently, is the act's shape. An act that creates still takes `id`, the id of the record it makes, and names it among what it takes; an act that does not create refuses an `id` it does not declare. An input its author made `z.looseObject` or gave a `catchall` keeps what it is not told about, as its author said; an argument given as `undefined` is no argument. Each such act's tool says `additionalProperties: false`, and `argumentsTaken` says what an act takes. The agent-seat skill says so.

Compatibility: breaking for a caller that sent an act an argument it does not declare — it was dropped and the act ran; it is refused now, `invalid`, naming what the act takes. Every app and fixture in this repository passes as it was. A derived tool's input schema changes for an unchanged declaration: every act whose input is a plain object says `additionalProperties: false` — announced for the `document:vendors` and `document:two-lines` conformance fixtures. `@graview/core` gains `argumentsTaken`. Unchanged for stored data, ops and the wire protocol. The pages face's budget rises from 488,500 to 489,000 bytes minified for the check (about 0.4 kB), and the embed without the studio's from 173,500 to 174,000 bytes gzipped with FR-119's reason. `capabilities().shipped` gains FR-121.
