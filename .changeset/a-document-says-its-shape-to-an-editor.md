A declaration document says its shape to an editor, and a document written in TypeScript is checked as it is typed. n-dx's projection is a 2,020-line JSON document that only `graview check` read: a key the format does not have (`fieldRoles` on a kind) was refused at run time, never underlined where it was written. Now every version of `@graview/core` ships `@graview/core/document.schema.json` (`dist/document.schema.json`), the document format as JSON Schema, which the build writes from the shape the compiler reads (`DocumentSpec`), never by hand. Its `$id` is the version's own published file (`https://unpkg.com/@graview/core@<version>/dist/document.schema.json`). A document that names it, `"$schema": "./node_modules/@graview/core/dist/document.schema.json"`, is checked in the editor as it is typed: every key, type, name pattern and range the compiler reads, every object closed so an unknown key is flagged, and the refinements said again in JSON Schema's words (at least one kind and at most 40, an enum's options and only an enum's, no field called `id` or `kind`). The compiler reads `$schema` and passes over it. A test holds the two together: every document in the tree that the compiler reads, n-dx's among them, validates, and an unknown key on a kind, a field, a relation, an act, a policy or the document fails both.

`defineDocument` from the new `@graview/core/typed` is the same document in TypeScript: it returns the JSON document unchanged, and a key the format does not have, an edge to a kind the document does not declare, a glance, page or lifecycle field its kind lacks, a relation an act connects or severs that no kind declares, a kind an act is on or creates, a kind a rule is over, and an act a repair or a grant names are type errors, each said as the names the document does declare. Expressions and templates are strings still, for `graview check`. n-dx's whole document checks under it in about a second.

The hosted page measures 34 bytes fewer up front (593 573, from 593 607, under its 593 613) and the same handed a compiled app (548 004): the `$schema` key is paid for by the pages arrangement's names saying their lengths through the schema's own helpers.

Compatibility: ops, stored formats, wire messages, the compiled format, check finding codes and tool names and schemas are unchanged. The document format gains an optional top-level `$schema` string, which the compiler reads past; every document that compiled still compiles, and one carrying `$schema` no longer refuses it as an unknown key. New: `@graview/core/document.schema.json`, and `defineDocument`, `CheckedDocument` and `DocumentDraft` on `@graview/core/typed`.
