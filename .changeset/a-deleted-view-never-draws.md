A deleted view never draws, a home's or an untitled one's either, whatever order views register in (FR-202). In Graview Cloud's Eagles app a home view deleted that morning (`eagles-story`) drew over the live one (`eagles-nest`): Cloud hands the page its deleted views too, so Restore works in place, and `tidyViews` kept a deleted view undrawn only by the name it registered under — which only a titled view of a kind had — while `views.home` went to whichever view registered last. Now `registerWorkerView` registers a home and an untitled view of a kind by the manifest's name too (a draft still by none), the registry keeps every home it is given in order with that name (`views.home(view, { name })`, `views.homes()`, the type `HomeRegistration`), `layerViews` lays each over with its name, and the tidied registry's `homeView` is the last home not deleted, its kind's picture the last view not deleted. A home's view fails over to the app's own home, the last one no view gave, rather than to another view a host may have deleted. Hiding keeps a place off the lists, and a view with no title is on none, so an untitled view only hidden still draws. `react`'s test registers the deleted home after the live one and the deleted untitled list after the live one, and draws the live ones; `guest`'s registers two homes and an untitled view and reads their names. `pnpm verify address` hands its page a deleted home view registered after the live one, with the host listing it deleted, and the home draws the live one (`aDeletedHomeViewNeverDrawsOverTheLiveOne`). A hosted page carries 0.2 KB more up front (194 bytes, about 58 gzipped; the compiled page the same), under a raise of each budget by that (`scripts/budget-raises/a-deleted-view-never-draws-*.json`), and the scene face's before-draw line is 996 KB. `capabilities().shipped` gains FR-202.

Compatibility: ops, stored formats, the wire, the declaration and derived tools are unchanged; `capabilities().shipped` gains FR-202. Additive on `@graview/core` (`ViewRegistry.home`'s optional `meta`, `ViewRegistry.homes`, the type `HomeRegistration`). What Graview Cloud does: hands the page every deleted view again, home and untitled ones included, and deletes `tidiedOnPage` (`workers/cloud/src/views.ts`, INTERIM(FR-202)) once `capabilities().shipped` has FR-202.
