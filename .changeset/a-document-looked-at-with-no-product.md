A document and a snapshot can be looked at with no product. `graview serve` was the store and drew nothing, so a stranger holding a JSON document and a seed had to build a product to see them — n-dx built one only to look at its projection, and proved every change with Playwright screenshots it scripted by hand. `graview preview <document.json> --seed <snapshot.json>` serves the same store and, beside it, Graview's own faces over it: the scene and Pages, with the bar and the address bar, so a place can be linked and reloaded. Nothing is built or installed at run time: the page is bundled once at the framework's build, as Graview Cloud's shell is, into the `graview` package's `dist/preview/` (71 files, 1.2 MB unpacked, about 430 KB of the tarball), so it rides with the tool a person runs and never with a product's dependencies. The store is in memory unless `--data` or `--sqlite` say where to keep it, and the page sits as a person holding every role the document declares unless `--as` or `--roles` say who. `graview shots <document.json> [--seed] [--places home,overview,people] [--out shots] [--scheme light|dark|both] [--width 1280,390] [--faces pages,scene]` photographs places headless to `<place>-<scheme>-<width>.png`: each place by its address word or its title, or a path such as `/people/p1`, every place when none is named; a place the app has not got is refused with the ones it has. Playwright is a peer the person installs, found beside the project first; without it the command says how to install it and the browser. `servePreview` and `previewPrincipal` are exported from `@graview/ship`, and `serveStore` takes an optional `answer(request)` that is asked before the store for every request but the live wire. `pnpm verify preview` runs the built command on Graview Cloud's org document and asks a browser for both faces, a change on the served store reaching the open page, and the shots. The ship and new-app skills say when to use them.

Compatibility: ops, stored formats, wire messages and routes, the document format, the compiled format, check finding codes and tool schemas are unchanged. Added: `serveStore({ answer })`, optional; a host that passes none serves exactly as before. The hosted page loads nothing more: no module it imports changed.
