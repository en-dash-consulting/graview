A static page draws a record's pictures, and a whole app renders to one file whose links stay inside it. `renderPlace` (`@graview/pages/static`) said a picture, video or document field by its file's name, so a host that exported an app as one HTML file drew a grid of pictures of its own beside the page. It now draws them as the hosted page does: a record's pictures in a gallery, each a link to itself full size and cut around its `focus`; a video with the browser's own controls from its poster; a document by the page its host made of it (`preview`), then by name, type and size; and a list's derived row or card with the record's first picture small, a declared one with its `image` blocks. Each is drawn at the address a new `files` option answers — the `files` the hosted page is handed, or only its `src` — and at the `href` the record keeps without it. `renderSite(store, declaration, { viewer })` writes every place and every record's page the viewer may see into one document: the look once, a contents of the places, each page an `<article>` with the id `pageAnchor(address)` gives, and every link one within the file, so the host rewrites no address; a link to a page the file does not hold is no link. A PDF is that file printed by the host's own browser engine: the sheet starts each page on a new sheet, keeps a picture whole, and sets a margin with `@page`, and nothing in a package runs a browser (`docs/static-pages.md`). `describePlace`'s field parts carry the `files` a field holds, beside the words they already said, and `sizeWords` and `typeWords` are `@graview/core/blocks`' so the static page says a file as the hosted page does. Held by `a-static-page-draws-a-records-pictures.test.ts` and `a-whole-app-is-rendered-to-one-static-file.test.ts`.

Compatibility: the look — unchanged on every face; a static page draws a field's files where it said their names, and its sheet gains the rules they and a site's pages use, and a 16 mm `@page` margin. The JavaScript API — added: `renderSite`, `pageAnchor`, `RenderSiteOptions`, `RenderedSite`, `SitePage`, `StaticFiles` and `RenderPlaceOptions.files` on `@graview/pages/static`; `sizeWords` and `typeWords` on `@graview/core/blocks` (still on `@graview/primitives`); an optional `files` on `describePlace`'s `field` part. Ops and primitives — unchanged. Stored formats — unchanged. The wire — unchanged. The declaration and check finding codes — unchanged. Derived tool names and input schemas — unchanged; `describe_place`'s answer carries a field's files beside their names.
