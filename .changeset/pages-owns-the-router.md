A design reaches the router through `@graview/pages`, and the routed face runs on React Router 8. A product's design, page or test used to import `Link`, `useParams` and the rest from `react-router-dom`, a dependency of its own, so a second copy or another major than the one `PagesApp` mounts left the page asking a router that was never set. `@graview/pages` now exports `Link`, `NavLink`, `MemoryRouter`, `useLocation`, `useNavigate`, `useParams` and `useSearchParams` (with `LinkProps` and `NavLinkProps`), always the router the face put above them, and which router answers is the package's business alone. React Router 8 has no `react-router-dom`, so the face imports `react-router` and asks for React 19.2.7 or later. `graview create` no longer writes `react-router-dom` into a project, writes React `^19.2.7`, imports `useParams` from `@graview/pages` in `src/ui/pages.tsx`, and leaves the router out of a linked project's `dedupe`, since the only copy is the one `@graview/pages` brings. A linked project's tests take that copy through vite (`server.deps.inline`), so it holds the project's React rather than the checkout's, and a project's build sets aside the router's `"use client"` without saying so, so a first build stays quiet. The example apps and `@graview/ship`'s README say the same. Tests: `a-design-reaches-the-router-the-face-runs-on` (pages) and the scaffold's `reaches the router through @graview/pages and never depends on it`. The pages face alone and every face grow by 3,228 bytes minified and shrink by about 400 gzipped, under a raise of each budget (`scripts/budget-raises/pages-owns-the-router-pages-face.json`, `scripts/budget-raises/pages-owns-the-router-every-face.json`). A hosted page's first load is unchanged.

Compatibility: ops and primitives — unchanged. Stored formats — unchanged. The wire — unchanged. The declaration and check finding codes — unchanged. Derived tool names and input schemas — unchanged. `@graview/pages` asks for `react >=19.2.7` where it asked for `>=18`. A product that imports from `react-router-dom` imports the same names from `@graview/pages` instead and drops `react-router-dom` from its dependencies and its `dedupe`.

What Graview Cloud does: nothing to change; it imports nothing from the router and runs React 19.3.
