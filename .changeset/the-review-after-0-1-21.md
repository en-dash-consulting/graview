What the review after 0.1.21 found, each fixed with a test that failed first.

A seat is read only what it sees, whatever it is handed. `resolveFor(store, principal, node)` resolved the record it was given as it was given, so a node read from the whole graph put its fields on a page for a seat that may not see it; it now reads the record through `store.seenBy(principal)`, and one the seat may not see resolves to nothing. `blockContextFor` with a principal and a bare `{ graph, schema }` says that a seat is read from a store, where it threw a `TypeError` about `seenBy`.

The doors answer only this machine's own pages. `sameOrigin` (`@graview/core/sync`) is now the one rule every door keeps — `mcpDoor` and the dev server's model, decision and studio doors alike (`@graview/ship/dev` re-exports it) — and it also refuses a Host that is not this machine (`ownHost`: `localhost`, a `*.localhost` name or an IP address, or one of the `hosts` a door is told), so a page that rebinds its own name to this machine can no longer spend the dev server's model key or call a sync's tools. `mcpDoor` takes only the media type `application/json` (not a type that merely mentions it, which a page on another site may send unasked), refuses a body past `limit` (1 MB) with a 413, and decodes it as UTF-8 across chunks.

`graview preview` keeps to its own page. It believes the seat its page names, so `serveStore`'s new `ownOrigin` refuses every request and live socket not from the preview's own origin on this machine; `servePreview` on a host other machines reach refuses unless `trustSeatHeaders` says the network is trusted (the CLI's `--trust-seat-headers`); `graview preview` takes a free port unless `--port` says one, where it took `graview serve`'s 5196; and a seed that does not read is said as `graview preview:` or `graview shots:` and a sentence, not a stack. `compileDocumentFiles({ seed })` and `graview view check --seed` read a seed in the snapshot's line format as well as an old `{ nodes, edges }` file.

The sync engine keeps to its policy at the edges. A write queued while offline is worked out again rather than replayed, so a field the next pull holds in conflict is not sent; a projected record is agreed at what it was made with, so an edit made before the first run is a conflict rather than lost; `guard()` holds `undo` and `redo` too, so the remote's own change to a record it owns cannot be taken back here, and it judges a patch as the record was and would be, so moving one out of what `match` reads is still a write to it; once it guards the store, `store.permits` and `store.permittedMutations` refuse an act on a record the remote owns with the resource's sentence, so it is not offered and then refused. A record deleted there is removed through the new `removeInbound`, or, without one, kept here and no longer synced or sent back as new; the report says which (`gone`). A held field whose value was taken here by an ordinary act (the conflict invariant's repair) is released, and `resolve` does nothing to a conflict a later pull already settled.

Each kind words its line everywhere (#205): the scene's Key lists every kind's reading of a shared relation, and the inspector's heading, its sentence when nothing acts on a line and the schema provider's reason say the words of the kind the line leaves. The scene's way back takes its offer off the board when the scene unmounts — a face switch on an embed's board that outlives it — and its Take back takes back only the act it offered. A turn with no system sends none. `defineDocument` holds a derived act's name (`edit-<kind>`, `remove-<kind>`) to a declared kind.

Compatibility: ops, stored formats, the document format, the compiled format, tool names and schemas are unchanged; the hosted page's first load is the same to the byte. The wire: additive — `serveStore` takes `ownOrigin`, off by default, so `graview serve` answers as before. Changed for a host: the dev server's doors and `mcpDoor` refuse a request whose Host is not this machine (`mcpDoor` may be told other names, `hosts`); `mcpDoor` refuses `text/plain` and a body past 1 MB; `graview preview` no longer defaults to port 5196. The declaration: `resolveFor` with a principal resolves nothing for a record that principal may not see. `SyncReport` gains `gone`, `SyncState` gains `gone`, and `SyncOptions` gains `removeInbound`.
