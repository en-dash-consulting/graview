A group is a place whether or not anybody is in it. Every branch that placed a focused group required it to have members, so going to a lens over an empty kind — which on a blank app is every kind — changed the address and drew nothing. The kinds named by an aggregate address are now checked against the declaration instead, so an empty group is a real place holding nobody and `aggregate:<undeclared>` still falls back to the default view.
