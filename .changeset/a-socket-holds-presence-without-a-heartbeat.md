A socket holds its presence without a heartbeat. On the live wire a presence lasted only by time: a client dropped anybody whose word was older than `REMOTE_PRESENCE_TTL_MS`, so `openRemote` said `here` again every `presenceEveryMs` (1.25 s) from every visible tab — and on a hibernating host each one woke the room, rewrote an attachment and told every socket: fifty tabs were about forty wakes and two thousand presence messages a second. Now the `here` a socket says comes back from the server stamped `held: "socket"`, and a presence held by a socket stands for as long as the server lists it: `presenceStands` and `foldPresence` do not expire it by its `at`, and the host drops it the moment the socket closes. `openRemote` says `here` down a socket only when where it stands changes, so an idle tab says nothing for as long as it is open and stays in the room. A client whose own socket dropped lets the held presences it was told go after `REMOTE_PRESENCE_TTL_MS` unless the server lists them again. A poller is held by time as before and says where it is with every poll; `presenceEveryMs` is now the opt-in for a heartbeat down the socket, for a host that still keeps a socket's presence by time.

Compatibility: presence and the live wire — additive. `Presence` gains optional `held: "socket"`, which only a server says: `presenceFrom` drops a client's claim of it, and `liveProtocol`'s `receive` stamps it on a socket's `here`. `WIRE_PROTOCOL` is unchanged. A host on `liveProtocol` that keeps `who` itself must forget a socket's presence when the socket closes, as `createStoreHandler` does — it is no longer forgotten by time. A client of this release on a host before it is not heartbeating by default, so a host that kept socket presence only by time should pass `presenceEveryMs`. `presenceEveryMs` no longer defaults to half of `PRESENCE_TTL_MS`. Ops, stored formats and check codes are unchanged.
