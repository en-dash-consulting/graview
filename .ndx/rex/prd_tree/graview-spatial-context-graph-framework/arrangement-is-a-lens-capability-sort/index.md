One headless module derives what a kind can be arranged by from its declaration — its fields by type, its edges, its lifecycle, its standing — and turns an arrangement into ordered groups; one grammar carries it in a stop (in.sort, in.filter, in.group in the fragment; the same keys in a page's search) so an arranged picture is a link; one control row draws it; and each default lens takes it through an option that can be turned off.
