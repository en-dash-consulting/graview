# Live demos

These are live demos of Graview: the example garden, running in this page. Nothing here is a screenshot. Each frame is the example garden, mounted on this page by `@graview/embed` from the same declaration, at a different place in it. [The garden, grown](https://graview.dev/progression.html) has all sixteen chapters, each with what the declaration gained.

## The city, at altitude

Every kind is a district; every record a building on its own plot; every edge a road with its words on it. Drag the ground, press a district, come down to a plot.

*The example garden at altitude, live: a live demo, on the HTML page.*

## The routed face

The same store as ordinary pages — here in the garden's own design: an almanac over the same acts, rules and log.

*The garden's routed pages, live: a live demo, on the HTML page.*

## The example apps

Each was built to prove a claim the others could not, and each is opened in a real browser on every push. They live under `apps/` in the repository; `pnpm apps` opens the desk, which opens the rest.

- [discography](https://github.com/en-dash-consulting/graview/tree/main/apps/discography): The example at real size: Tech N9ne's discography from MusicBrainz — 1,177 songs, 568 artists, 479 releases.
- [gauntlet](https://github.com/en-dash-consulting/graview/tree/main/apps/gauntlet): The example built to be awkward: ten years of a conference's program, with every shape of data the walks found by accident declared on purpose.
- [rota](https://github.com/en-dash-consulting/graview/tree/main/apps/rota): The product-grade example: a volunteer shift roster, branded, permissioned, remembered, embedded and open in its own studio.
- [seedbed](https://github.com/en-dash-consulting/graview/tree/main/apps/seedbed): A community garden, and the chapters the docs teach from. It opens on the example garden; Start empty gives the blank graph, where onboarding is filling it in.
- [todo](https://github.com/en-dash-consulting/graview/tree/main/apps/todo): The example. A todo list, because nobody has to be taught what one is.
