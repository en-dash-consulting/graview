Declare the domain. The application follows.

Declare what your domain is made of — the kinds of thing, how they connect, the acts that change them, the rules they must not break — once, as code. The interface, the pages, the permissions, the checks and an agent's tools all come from that one declaration.

npm create graview@latest my-app

Writes a running app with one kind, one act, one rule, a routed face, a headless test, a CI workflow and the skills — then pnpm verify tells you it works.

  • 71 things the checker can say
  • 1184 named tests, green
  • The picture. Every kind is a district of one city; every record is a card among its relations; the words on the lines are the declaration's own, read from whichever end you are standing on.
  • The acts, and the checks. What a selection may have done to it comes from the mutations and the policy — a seat never sees a button that would fail. graview check reads the whole declaration and says what is wrong before a page does.
  • The pages. The same declaration, routed: lists, records and forms for the person who wanted an ordinary web app — and every surface replaceable, up to a product design of the app's own over the same store.
  • The agent's seat. Every act is a typed tool with a sentence attached. A model works the same graph, in the same operation log, under the same policy, and its turns can be taken back.

It is built to be worked on with an agent. The declaration is a context graph, and a context graph is the one thing a model reads as well as a person does. Open a session beside the declaration and work it together: describe a kind, let the model draft its edges, its acts and its rule, run graview check, look at the picture, declare more. The skills that ship with the framework teach the model the shapes; the checker tells you both when a shape is wrong; every act the model takes lands in the log with its author, its intent and its inverse. It is not a UI layer bolted onto a store: the graph, the rules, the log, the tool surface and the pictures are one system, and they ship as packages you install.

Built to be worked on with a model

A declaration is a context graph, and a context graph is the one thing a model reads as well as a person does. Not a chat box bolted to a CRUD app — the same object is the source for your interface, your agent's tools and the checker that keeps them honest.

It can read the whole app

graview describe reads the declaration and says what somebody opening the product for the first time can actually do — derived, so it cannot drift. This is real output, from a real app:

It can write it, and you see what it would do first

Every act is a typed tool with a sentence attached, narrowed by the same policy a person is under. What comes back is a plan before it is a change: one row per thing, what it was sure about, what goes with what if you decline something, and then one batch with one undo.

  • The same acts. No privileged write path. A model's edits produce the diffs a person's do, in the same log, under the same rules.
  • Attributed and reversible. Every turn carries its author and its intent, and comes back out through the same control.
  • Refused out loud. An act a seat may not take is struck through with the sentence saying who can — never a button that silently fails.
  • 13 skills ship with it. Each teaches a model one shape of the declaration and ends in graview check, reporting what it actually said.

The loop is the whole method, and it is the same loop whether the hands are yours or a model's: describe a kind, let it draft the edges, the acts and the rule, run graview check, look at the picture, declare more. The checker tells you both when a shape is wrong — 71 things it can say, in words, before a page does.

What you do not write

All of this is derived from the one declaration. Every piece of it is replaceable, and none of it has to be.

  • The picture. Every kind is a district of one city; every record a card among its relations; the words on the lines are the declaration's own, read from whichever end you are standing on.
  • The acts, and the checks. What a selection may have done to it comes from the mutations and the policy — a seat never sees a button that would fail. graview check reads the whole declaration and says what is wrong before a page does.
  • The pages. The same declaration, routed: lists, records and forms for the person who wanted an ordinary web app — and every surface replaceable, up to a product design of the app's own over the same store.
  • The agent's seat. Every act is a typed tool with a sentence attached. A model works the same graph, in the same operation log, under the same policy, and its turns can be taken back.
  • The way in. An empty installation is the screen nobody designs. beginning() reads the chain out of the declaration and says what can be made now, what the rest are waiting for, and — for a seat that may not — who can.
  • Six lenses. A timeline, a calendar, a matrix, a board, a reach and a plan. Each binds roles rather than field names, so one written for your domain works unchanged in somebody else's.

Install

$pnpm install && pnpm buildthe framework, first
$pnpm graview create ../my-app --link .chapter one, written for you
$cd ../my-app && pnpm verifytypecheck, tests, build, check
$pnpm dev:seedbedthe garden — ?chapter=N opens any chapter
$pnpm progressionevery chapter, photographed
$pnpm testheadless, no browser

Start with the garden. Fifteen chapters, from one kind to a shipped, branded, permissioned application with a lens and an agent's seat — each a real declaration you can open with ?chapter=N. graview create writes chapter one for your own domain; the packages are not on a registry yet, so a product starts from a checkout and consumes the framework by path. The todo example is the second thing to read: four kinds, eleven acts, three rules, a lens borrowed from a calendar.

The scene renders through the DOM by default. The plane model is affine, so a CSS transform reproduces the geometry exactly; what it cannot do is per-plane blur in a shader. ?renderer=gpu composites through WebGPU instead.

Status

Private, and unpublishable on purpose. Every package is private: true and carries no licence. Publishing without one would leave whoever installs it with no permission to use it. That is a decision waiting to be made, not work waiting to be done.
  • The capture path is experimental. Capture falls off a cliff past about 128 live captures a frame, and every claim above is measured against the DOM path. Use it for the per-plane blur, not because it is faster.
  • The calendar sync has never run against Google. Echo suppression, conflict detection and offline reconciliation are covered against a scripted remote. A token that expires mid-run is not.
  • No screen-reader pass with real assistive technology. The tree is populated and axe-core reports nothing. A populated tree is not proof that VoiceOver reads it well.
  • The public API is pre-1.0. Every package exposes a single src/index.ts and nothing else is supported, but the surface still moves while nobody depends on it.
